To-Do List Web App

This is a clean and minimal To-Do List application that helps users organize their daily tasks. Built using HTML, CSS, and Vanilla JavaScript, this project demonstrates DOM manipulation and basic event handling in JavaScript.

🚀 Features

➕ Add new tasks

❌ Delete tasks

📋 Real-time task update

💻 Simple and clean UI

📱 Responsive design

🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6)
